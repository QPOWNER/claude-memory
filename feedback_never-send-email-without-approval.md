On 8/5/26 the user said "Answer her" about a customer email; I composed AND sent the reply via Chrome/Gmail. The user was upset: "Why did sent it !!!!!!"

**Why:** "Answer her" (and similar: "reply to him", "respond") means WRITE the answer, not send it. Every email workflow the user has set up is draft-based ([[draft-order-from-quote-request]] — never auto-send invoice; [[approval-mockup-email]] — Gmail drafts). The user always reviews outgoing mail, especially anything committing money, policy, or tone.

**How to apply:** Always create a Gmail draft and tell the user it's ready for review. Never click Send in the browser and never use any send-mail capability, no matter how the request is phrased, unless the user explicitly says to send an exact text they have already seen (e.g. "send that draft as-is").

**Same rule for money (added 8/5/26 after second complaint "and refund on my name what up with you??"):** Never promise refunds/discounts/credits in the user's name, and never attempt to execute a refund or any money movement (Shopify refundCreate, CLI, PayPal, anything). Drafts that mention money must leave the commitment open (e.g. "we're looking into it") unless the user has already stated the exact resolution. Present options + recommendation; the user decides and executes.
